# Deviations from upstream Hermes

NUMBERS is a **100% identical clone of the Hermes CLI** — every provider, every
toolset, every capability — with exactly four Intersession-specific differences:
custom Angel MCP server, custom branding (the `numbers` skin), a custom isolated
workspace (`NUMBERS_HOME`), and **no Gemma**. The table records the source-level
deviations; branding and the MCP entry are pure config/skin, not source patches.

## Removed (no longer shipping Gemma)

| Date | File | Change |
|---|---|---|
| 2026-09-09 | `numbers_ext/gemma.py` (+ tests) | Deleted the local-Gemma supervisor. NUMBERS ships no local model. |
| 2026-09-09 | `numbers_ext/onboarding.py` (+ tests) | Deleted the Gemma-first welcome; stock `agent.onboarding` covers first-run provider guidance. |
| 2026-09-09 | `numbers_ext/detect_providers.py` (+ tests) | Deleted the 3-provider allowlist. Provider choice now uses stock Hermes `numbers model` / `numbers auth`, which supports every Hermes provider. |

Note: stock Hermes support for *talking to* a Gemma model (tool-call parsing,
the `google/gemma-4` alias in `cli.py` / `run_agent.py`) is upstream capability
and is intentionally kept — "no Gemma" means we do not bundle/default/supervise a
local Gemma, not that we strip Hermes' model-format support.

Anything added to this table must first fail the four-step escalation in
`core_implementation.md` §3: (a) MCP tool, (b) skill, (c) config, (d) prompt preamble.
